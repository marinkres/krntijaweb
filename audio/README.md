# Demo audio

The A/B player on the page loads two files from this folder:

- `before.mp3` — the dry loop, straight out of the DAW
- `after.mp3` — the same loop rendered through KRNTIJA.VI

Both are bounced from the **same** loop at the **same** length and the **same** starting
point. The player keeps them locked to one another and only swaps which one is audible,
so any offset between the files shows up as a jump when you hit the switch.

Keep them short (8–16 s) and normalise them so the difference you hear is the plugin,
not a level change.
